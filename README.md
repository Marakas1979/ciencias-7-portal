# Ciencias 7 · Portal para estudiar y practicar

Portal estático y autocontenido en `index.html`. Para usarlo, abre el archivo en un navegador. No requiere instalación, cuenta ni conexión a un servidor.

Incluye 12 pantallas de estudio, preguntas cortas por tema, una prueba final interactiva, controles de tamaño de letra y enlaces a la guía y a las pruebas en PDF dentro de `recursos/`.

El avance se conserva localmente en el navegador del dispositivo. No se envían respuestas ni datos. Para borrar el avance, usa el botón del índice.

Contenido organizado a partir del temario de Ciencias de 7.º y las páginas fotografiadas por el usuario. Nivel y conceptos del programa se mantienen; la presentación se divide en bloques breves.
